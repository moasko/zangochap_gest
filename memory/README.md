# Mémoire du projet

Ce dossier contient un contexte durable pour les assistants IA et les nouveaux
contributeurs. Il doit rester synthétique, factuel et à jour.

## Fichiers

- `project-context.md` : architecture, domaines, flux et risques connus.
- `change-log.md` : journal des changements importants apportés avec assistance IA.

## Règles

- Ne jamais stocker de secrets, valeurs de `.env`, mots de passe ou données personnelles.
- Distinguer les faits vérifiés des hypothèses.
- Indiquer une date de dernière vérification.
- Mettre à jour uniquement les informations réellement affectées par une intervention.
- Le code, le schéma Prisma et `AGENTS.md` restent les sources d'autorité.
